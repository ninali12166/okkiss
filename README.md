# CrisisLens — AI 营销公关决策情报库

> 把危机案例，训练成可调用的营销判断。

CrisisLens 是一个面向 AI 营销解决方案岗位的独立作品。项目将 111 个中国与海外公关事件结构化为可检索、可比较、可生成策略简报的决策知识库，展示从资料采集、AI 辅助标注、人工复核到策略输出的完整产品思路。

## Live Demo

**[打开在线项目](https://pr-case-library.earthyshore32.chatgpt.site)**

## 核心功能

- 111 个中国与海外公关案例
- 按区域、行业、危机类别、结果与关键词组合检索
- 事件背景、企业响应、真实公众反应和成败原因分层展示
- 双案例并排对比
- 根据当前筛选样本动态生成危机响应简报
- CSV 数据导出
- “深度核验 / 研究索引”资料成熟度标记
- 响应式桌面与移动端体验

## B.L.U.E. 决策框架

| 维度 | 核心问题 |
| --- | --- |
| **B — Behavior** | 企业最先做了什么？行动是否先于声明？ |
| **L — Listening** | 真实公众在担心、愤怒或嘲讽什么？ |
| **U — Utility** | 补救是否真正降低用户风险和决策成本？ |
| **E — Evidence** | 承诺是否有来源、数据、责任人与时间表？ |

## AI 工作流

```text
公开资料采集 → AI 辅助结构化 → 人工编辑复核 → 模式聚类 → 策略调用
```

AI 用于提高信息处理与模式发现效率；案例评分、事实与判断的边界、伦理风险和最终策略由人工把关。

## 项目定位

这是一个独立学习与求职作品，并非蓝色光标或案例中任何企业的官方项目。案例内容来自公开资料，编辑分析仅用于研究和课堂讨论；“研究索引”案例建议继续通过来源入口交叉核验。
